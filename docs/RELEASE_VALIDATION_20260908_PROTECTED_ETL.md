# 2026-09-08 受保护数据加工发布验证记录

## 发布范围

本次仅修复当前对话确认的三个问题：

1. 当前平台登录者均为超级管理员；安全访问限制面向平台外部的 Doris 下游业务账号或应用账号。
2. 受保护批次不再把 DWD 数据加工强制塞入只允许查询的 `restricted`（受限查询）模式，改为 `protected_etl`（受保护的数据加工）模式。
3. 工作台中的“普通用户”文案改为“Doris 下游账号”。

未修改平台角色体系、Doris 账号授权、数据恢复、同步、SM4 算法、OpenMetadata 出站或其他审计建议。

## 行为规则

- `protected_etl`（受保护的数据加工）允许查询、`INSERT ... SELECT`（写入并查询）和 `CREATE TABLE ... AS SELECT`（建表并查询）。
- 使用 Doris 专用 SQL 语法解析器处理副本、分桶等 Doris 建表语法。
- 只把冻结安全合同中的 ODS 读取来源替换为已激活的安全访问别名，不修改 DWD 写入目标。
- 正常批次和失败重试都必须携带该批次冻结的安全编排快照。
- 缺少冻结合同、映射未激活、合同映射歧义或尝试写回冻结 ODS 明文来源时直接阻断，不允许回退到明文。
- 原有 `restricted`（受限查询）模式继续只允许查询，供管理员验证 Doris 下游账号的安全访问效果，不改变既有兼容行为。
