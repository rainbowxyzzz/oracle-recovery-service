# 数据变化触发器独立子流程发布验证

验证日期：2026-07-16  
验证环境：`192.168.150.128:8000`  
对应需求：`docs/DATA_CHANGE_TRIGGER_ORCHESTRATION_PRD.md`

## 已实现

- 数据变化触发器独立任务列表和专用三栏工作区。
- 固定数据变化监控入口节点。
- 触发器内部画布支持引用 SM3、SM4、Doris SQL、数据同步/ETL 已保存任务。
- 支持节点前移、后移、删除和串行依赖展示。
- 支持保存草稿、校验、发布、启用、暂停、立即巡检、运行一次内部流程和删除。
- 发布时冻结内部业务任务修订并生成系统隐藏工作流版本，运行复用离线 DAG 执行器。
- 发布后的触发器支持三态水位、首次基线、变化命中、内部动作执行和成功后推进应用水位。
- 自包含触发器在离线画布中禁止连接外部上下游，防止重复执行；旧版入口型触发器保持兼容。
- 离线开发任务列表不展示触发器内部生成的系统工作流。

## Chrome 验证

使用真实可见 Google Chrome，通过 CDP 操作页面并验证：

- 新建触发器。
- 配置 Doris 连接、数据库、数据表和巡检周期。

- 保存草稿、校验、发布、启用、首次巡检和变化后巡检。
- 触发 SQL 动作并验证 Doris 目标表写入结果。
- 运行一次内部流程。
