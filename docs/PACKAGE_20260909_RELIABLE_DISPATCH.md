# 20260909 数据自动化可靠派发完整包

## 版本与边界

- 版本：`20260909-data-automation-reliable-dispatch-r1`。
- 包结构沿用最近完整 Docker Run（无需编排工具的容器运行）包，仅增量更新当前源码、测试、镜像标签和本版说明。
- 本次只生成完整离线部署包并执行本地及 Linux（服务器操作系统）包级验证，不发布、不替换 `192.168.150.128` 服务。
- 不包含 Oracle、Doris、SQL Server、MySQL 恢复目标库等业务数据库镜像，也不包含环境凭据或业务数据。

## 本版内容

- 数据自动化阶段新增可靠派发表，批次状态、执行目标和待派发记录在同一系统库事务中提交。
- 调度派发失败支持有界退避重试和陈旧任务恢复，任务编号保持确定性，避免重复执行。
- 数据同步、SQL 工作流、SM4 加密和 Oracle 还原后台任务增加原子认领与幂等保护。
- 数据流编排与运行台账显示待派发、已派发、运行中、成功和失败状态，区分“尚未进入队列”和“正在执行”。
- 保留此前完成的 ODS（贴源数据层）反向加密、安全别名、受保护 ETL（抽取、转换、加载）、字段血缘、SQL 集合工作台、统一身份退出和 Keycloak（统一身份认证服务）主题能力。
- 镜像新增 `SQLGlot 29.0.1`（SQL 语法解析器）运行依赖。

## 配置变化

- `.env.example` 原有字段顺序和默认值保持不变，只更新本版镜像标签与镜像归档名。
- 在安全配置分组末尾追加可选 OIDC（开放身份连接协议）配置，其中 `OIDC_POST_LOGOUT_REDIRECT_URI` 用于 Keycloak 全局退出后的回跳地址。
- 统一身份主题随包放在 `keycloak-theme/unified-identity`，启用步骤见该目录的 `README.md`。
