## 范围

## 实现

- 数据库测试和新建 Oracle 还原任务共用解析规则：DSN 优先，否则地址:端口/Service Name，Service Name 为空时使用历史 PDB。
- 自动还原预检查、正式工具和停止任务保留完整连接，不再截断为服务别名；不硬编码 localhost，也不修改数据库、目录或字符集路由配置。
- SQLPlus 使用 `-L`，失败立即返回，不再把后续 SQL 当成重试登录输入；数据库密码按 Oracle 登录语法引用。
- 连接页面区分数据库登录与 SSH 执行环境，主要字段保留 Service Name；高级配置保留 DSN 和历史 PDB，冲突时显示实际优先级。为兼容现有接口，自定义 DSN 模式仍保留档案中的 host 字段，但明确其不参与 Oracle 登录。
- 新增无密码配置摘要、密码留空保留提示、未保存修改拦截；测试结果分数据库、SSH、容器、容器内 PDB，失败保留之前已成功阶段。
- 还原页显示所选连接摘要，任务详情区分创建时快照与事件记录的运行目标。历史任务不随连接编辑而变更。

## 内置浏览器验证

使用 `artifacts/oracle-connection-ui-preview.py`，仅监听 `127.0.0.1:18080`，接口数据在内存，不调用 Oracle、SSH 或生产服务。

1. 打开旧 Oracle 连接，核对服务名、历史 PDB、SSH、容器和摘要回填。
2. 修改服务名，不保存点击测试：明确提示先保存，没有发出测试请求。
3. 保存并刷新：服务名更新；检查 PUT 请求未包含留空的数据库/SSH 密码，历史 PDB 未被清空。
4. 切到自定义 DSN 并保存：重新打开仍为自定义模式；摘要及连接列表显示 DSN。
5. 模拟数据库成功但 PDB 失败：页面四项分别显示，未误报整体成功。
6. 切回标准模式、清空 Service Name 并保存：请求的 DSN 为 null，刷新后摘要回退历史 PDB。
7. 新增 Oracle 连接并保存；再切为 MySQL，保存默认库并重新进入，原默认库能力保留；默认连接“是/否”均有保存覆盖。此页面没有启用/停用字段，未虚构该验收。
8. 打开还原页，在 Oracle/MySQL 间切换，连接摘要随目标连接更新，未提交实际还原任务。
9. 1366×768、1440×900、1600×900、1920×1080、960×900、768×720 的页面 DOM 宽度测量均没有页面级横向溢出；验证时浏览器控制台未出现应用错误。
