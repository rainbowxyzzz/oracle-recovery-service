# 查询导出中心 PRD

## 目标

为 Doris SQL 工作台的只读查询增加异步、大结果、可审计导出能力。浏览器仅展示预览，完整结果由独立导出 Worker 流式生成后提供受控下载。

## 格式与模式

- 支持 `csv`、`tsv`、`jsonl`、`xlsx`、`parquet`；CSV 支持 UTF-8、UTF-8 BOM、GBK。
- `streaming`：默认模式，服务端游标配合 `fetchmany`，批次写入，不允许 `fetchall`。
- `parallel`：仅允许可证明的分区查询，按管理员上限拆分子任务；首版不自动猜测分区键。
- `columnar`：Parquet 分批生成，面向分析场景。
- `native`：Doris 原生 `OUTFILE` 仅在目标存储已配置且具备专用权限时可用；首版不默认启用。

## 资源与安全

- 导出任务进入独立 `data_export` Celery 队列，默认任务并发 1、线程数 1；高性能档最多使用容器可用 CPU 与管理员上限中的较小值。
- 单任务内存预算默认是导出 Worker cgroup 内存限制的 50%，并受固定上限约束；无法读取限制时使用保守固定预算。
- 可用内存低于 10% 时告警并暂停领取新任务；超过任务预算时安全失败并保留已完成的分片和审计记录。
- 临时文件目录、最终文件目录必须位于持久化挂载；启动前检查磁盘空间。
- 每个任务记录 SQL 摘要、参数摘要、格式、行数、大小、SHA256、资源档位、创建人、下载人及过期清理结果；不保存完整结果到系统元数据库或日志。
- 每批写入后记录已处理行数、已写入字节、当前阶段与行处理速率；不为未知总量的大查询额外执行 `COUNT(*)`，前端以不定量进度条展示运行状态。已排队或运行的任务可由创建人取消。
- 下载必须鉴权：创建人可下载自己的文件，管理员可下载他人文件；链接与文件均有过期时间。

## 验收

使用隔离 Doris 表验证流式 CSV、TSV、JSONL、XLSX、Parquet 五种格式；验证文件内容、行数、下载鉴权、过期清理、进度写入、取消、资源告警和 API/Worker 健康。百万级验证以生成任务、分批读取、内存峰值与文件分片为准，不得让 API 进程读取完整结果。
