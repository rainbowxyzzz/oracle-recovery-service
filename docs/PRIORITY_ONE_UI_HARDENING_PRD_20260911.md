# 一级优先级交互强化 PRD

日期：2026-09-11

## 1. 背景与目标

本轮只处理全系统交互审查确认的四项一级优先级问题：数据库清理计划失效保护、数据流业务引用选择、SM4 安全访问覆盖合同维护、离线开发节点参数与字段映射维护。

目标是降低错误配置和误执行风险，复用现有接口、配置字段和业务执行器，不重新设计业务流程。

## 2. 兼容性边界

- 不改变现有 API 地址、请求字段、响应结构、数据库结构、权限、调度、密钥、加密、恢复、同步或离线工作流执行语义。
- 已保存的 UUID、覆盖合同、节点配置和字段映射继续按原结构保存。
- 旧配置引用的任务或连接已归档、删除或当前不可见时，页面必须显示“历史引用”，并在用户明确修改前保留原值。
- JSON 继续作为后台兼容存储结构，但普通编辑路径改为结构化控件；原始 JSON 只作为高级兼容入口。
- 本轮不发布到 128、不打包，除非用户后续明确授权。

## 3. 数据库清理计划失效保护

- 清理计划必须绑定生成计划时的连接、目标集合、删除存储选项和残留文件选项。
- 计划生成后，上述任一输入发生变化，前端立即作废旧计划、隐藏计划内容、禁用执行按钮并提示重新生成。
- 执行前再次比较当前输入与计划快照；不一致时不得调用批量执行接口。
- 保留后端执行前重新生成计划和保护系统库的既有校验，不增加新的删除能力。

## 4. 数据流业务引用选择

- 新建或编辑业务数据流时，恢复模板、数据同步任务、DWD 工作流生产版本、ODS SM4 任务和 Doris 连接使用可搜索或原生选择控件，不要求用户识别 UUID。
- 选项展示业务名称、版本、状态和关键目标；提交仍只发送现有 UUID 字段。
- 页面显示所选引用摘要和不可用状态。历史引用不在当前可选列表时，必须临时补入并保留。
- 打开表单前刷新已有任务引用；单个引用接口加载失败时显示错误，不得清空已保存值。

## 5. SM4 安全访问覆盖合同

- 覆盖合同按行维护标准库、标准表、标准字段、ODS 源库、ODS 源表、ODS 源字段和安全访问库。
- 支持新增、删除、保存和取消；保存前校验必填项，同一来源字段不得出现重复合同。
- 结构化编辑结果继续写入现有 `coverage_contracts` 数组，不改变 SM4 任务修订、引用冻结和运行语义。
- 原始 JSON 放入高级兼容区；从高级区应用时必须解析为数组并重新渲染结构化表格。

## 6. 离线开发结构化配置

- 节点模板参数使用“参数名称、值类型、参数值”表格维护，支持文本、数字、布尔、空值和 JSON 值；保存结果继续写入现有节点 `config` 对象。
- 复杂或历史节点参数必须能通过高级 JSON 兼容区完整读取和保存，不能因结构化编辑丢失嵌套对象或数组。
- 数据同步组件字段映射使用“来源字段、目标字段、目标类型”表格维护；空表格继续表示全部字段同名同步。
- 组件保存仍提交现有 `column_mapping` 数组，不改变同步方式、写入策略、结构基准或运行规则。

## 7. 验收标准

1. 清理计划生成后改变目标、连接或删除选项，执行按钮立即失效；不重新生成计划不能发出执行请求。
2. 数据流表单可通过名称选择五类引用，保存请求字段与旧版本完全一致；刷新和重新打开后正确回填。
3. 已删除或不可见的历史引用不会在打开、保存过程中被清空。
4. SM4 覆盖合同可逐项新增、修改、删除、取消和保存；编辑旧任务时能从原数组完整回填。
5. 节点参数和字段映射可通过结构化控件完成填写、选择、确认和保存；高级 JSON 与结构化视图双向一致。
6. 既有恢复、同步、DWD 工作流、SM4 任务保存与运行、数据库清理计划和权限行为回归通过。
7. 前端脚本无语法错误；在支持的可见浏览器中完成表单填写、选择、弹窗开关、取消、保存、刷新回填和确认路径检查。
