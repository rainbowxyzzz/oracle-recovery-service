# 20261009 A 服务器完整包 R3

R3 延续 R2 的包内镜像版本清单和 Oracle 启动诊断，并根据 128 全新创建 UTF Oracle 的实际验证结果补充以下修复：

- 旧 `.env` 未配置 `ORACLE21C_PASSWORD` 时，全新 UTF Oracle 自动复用现有主 Oracle 容器的 `ORACLE_PWD`。
- 用户无需为第二套 Oracle 重复填写密码，也不需要把 UTF 模式改为 `external`。
- 该逻辑只读取主容器配置，不输出密码，不修改主库及其数据目录。

本版继续保留 R1 应用镜像内容，不重复构建镜像；变更范围仅为部署脚本、回归测试、包清单和文档。
