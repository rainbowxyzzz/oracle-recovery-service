## 1. 页面骨架

桌面端以 `1360px` 内容最大宽度为视觉基准；小于该宽度时左右内边距保持，内容随视口收缩。

```text
┌──────────────────────────────────────────────────────────────┐
│ Global bar · 42px · 深色 · 平台名称                           │
├──────────────────────────────────────────────────────────────┤
│ Main nav · 66px · 白色 · 品牌 / 一级业务域 / 搜索与快捷入口   │
├──────────────────────────────────────────────────────────────┤
│ Mega menu · 覆盖式 · 仅 open 时显示 · 业务域说明 / 模块       │
├──────────────────────────────────────────────────────────────┤
│ Workspace canvas · 浅灰背景 · 既有模块工作区                  │
└──────────────────────────────────────────────────────────────┘
```

| 区域 | 固定规格 | 说明 |
|---|---:|---|
| Global bar | 高 `42px`；左右 `28px` | 深色平台标识栏；只显示平台名称。现有用户与系统管理入口保留在 Main nav，不展示无实际入口的占位文字。 |
| Main nav | 最小高 `66px`；左右 `28px` | 白色主导航；品牌、一级业务域、搜索/快捷入口同行。 |
| 内容最大宽度 | `1360px` | Main nav 与 Mega menu 内层使用同一宽度和居中规则。 |
| Mega menu | `max-height: 330px` | 位于 Main nav 下方，绝对定位覆盖工作区，不推挤页面内容。 |
| Mega menu 内边距 | 上 `24px`、左右 `28px`、下 `26px` | 双栏间距 `26px`。外层全宽铺底，仅内部内容居中。 |
| Workspace canvas | 上 `44px`、左右 `28px`、下 `54px` | 浅灰背景，保留既有模块工作区。 |

## 2. 一级业务域

一级菜单固定为下列顺序，显示在 Main nav 的同一行。不得把二级模块直接平铺在一级菜单下。

1. 数据接入
2. 数据开发
3. 数据流转
4. 权限服务
5. 数据安全
6. 服务与治理
7. 系统与助手

单个一级菜单规格：高随 Main nav 拉伸（`66px`），水平内边距 `14px`，字号 `14px`，默认文字色 `#344054`，白色透明背景。下划线距离左右各 `14px`、高 `3px`、圆角 `3px 3px 0 0`。

已选中业务域由当前模块决定；选中状态使用文字 `#1677ff`、字重 `650`、蓝色下划线。悬停或预览状态使用文字 `#1677ff` 和背景 `#f7fbff`，不得覆盖当前模块所属业务域的 active 下划线。

## 3. 二级 Mega Menu

二级菜单是 Main nav 下方的**全宽覆盖面板**，不是多个独立小气泡，也不是多列常驻菜单。

桌面端内部采用双栏 Grid：`230px minmax(0, 1fr)`。外层白色底板全宽展开，阴影只位于其底边；内部内容以 `1360px` 居中，不形成居中的悬浮大卡片。

| 栏位 | 规格 | 内容 |
|---|---|---|
| 左栏：业务域说明 | 宽 `230px`；右内边距 `24px`；右边框 `1px #e4e7ec` | `BUSINESS DOMAIN` 标识、业务域名、说明、模块数量。 |
| 右栏：模块卡片 | 两列等宽；间距 `10px` | 当前业务域的全部二级模块。 |

模块卡片：最小高 `72px`，内边距 `12px 14px`，圆角 `7px`，默认透明边框。模块名 `14px / 650 / #101828`，说明 `12px / #667085`。不展示与模块卡片重复的“常用入口”。

二级模块与现有模块的映射固定为：

| 一级业务域 | 二级模块 |
|---|---|
| 数据接入 | 数据连接、数据导入 / 恢复、Doris CSV 导入 |
| 数据开发 | Doris SQL 开发工作台、离线开发、数据自动化流水线 |
| 数据流转 | 数据同步、数据变化触发器 |
| 权限服务 | 批量授权中心、审批流自动授权、数据空间批量开通 |
| 数据安全 | Doris SM4 加密中心、SM4 调度中心、Doris SM3 映射脱敏、SM3 日志审计 |
| 服务与治理 | 接口编排中心、OpenMetadata 数据目录、数据库清理、帮助与架构中心 |
| 系统与助手 | Harness 智能助手 |

## 6. 状态与动画规则

| 状态 | 一级业务域 | Mega menu | 二级模块 |
|---|---|---|---|
| default | 默认文字，无下划线 | 不显示 | 默认卡片。 |
| hover / focus | 文字蓝色，背景 `#f7fbff` | 打开当前业务域的菜单 | 可点击。 |
| active | 当前模块所属域保持蓝色下划线 | 不等于必须打开 | 当前模块卡片浅蓝底与强调边框。 |
| open / locked | 点击后的业务域保持 preview 外观 | 保持打开，直到点击其他业务域或菜单外部 | 可继续选择。 |
| close | 恢复 default 或 active | 隐藏 | 不改变当前模块。 |

动画只允许用于 Mega menu 和模块卡片：

- 打开：`max-height` 从 `0` 到 `330px`，时长 `280ms`，缓动 `cubic-bezier(.2,.8,.2,1)`；同时 `opacity: 0 → 1`（`200ms`）与 `translateY(-10px) → translateY(0)`（`280ms`）。
- 关闭：使用相同属性反向执行；面板关闭后 `pointer-events: none`。
- 模块卡片 hover / current：背景与边框 `180ms ease`，仅允许 `translateY(-1px)`。
- `prefers-reduced-motion: reduce`：移除全部 transition，不保留循环动画。

## 7. 响应式规则

| 断点 | 固定规则 |
|---|---|
| `> 860px` | 使用完整双栏 Mega menu。 |
| `<= 860px` | Global bar 仅保留平台名称；Mega menu 只保留模块卡片单列，隐藏左侧说明；内边距改为 `18px 16px`，展开最大高 `390px`。 |
| `<= 520px` | 模块卡片保持单列；品牌字体 `15px`；工作区标题 `22px`。 |

一级业务域在窄屏横向滚动，不换成多行，也不出现页面级横向滚动。

## 8. 与当前项目的冲突（实施前必须确认）

1. 当前 `ui.html` 使用固定白色 `header`（约 `56px`）加独立固定 `.side-nav`，页面预留 `120px` 顶部空间；原型使用 `42px + 66px` 的两层导航和覆盖式 Mega menu。两者的固定定位、页面顶部预留和移动端高度直接冲突。
2. 当前 `header` 中已有 API 文档、系统管理、用户与 API Key 相关控件；原型的 Global bar 只定义了全局入口的视觉位置，未定义这些既有控件的完整映射。不得删除、改名或隐藏这些入口。
3. 当前顶部菜单的 `.nav-domain-group` 已按权限动态隐藏二级模块；原型只定义视觉分组。Phase 1 不得移除 `data-nav-module`、权限隐藏逻辑或模块面板 ID，Phase 3 才能接回这些行为。
4. 当前主工作台已发布 OIDC 登录和系统管理菜单；原型未包含登录态、用户菜单或权限不足状态。不得用原型静态文案覆盖这些现有能力。
5. 顶栏固定定位已确认：生产页面使用固定顶部导航；固定高度为 Global bar `42px` 加 Main nav `66px`，页面顶部预留 `108px`。原型中的普通文档流展示不作为生产实现依据。

## 9. 分阶段边界与验收

### Phase 1：静态 UI

- 只实现本规范中的 Global bar、Main nav、默认收起的 Mega menu 外壳、静态工作区排版、字号、颜色、间距、边框和圆角。
- 不绑定 hover、click、active、open、close、权限、模块切换或已有 API。
- 验收：1366×768、1440×900、1920×1080 下，默认态只显示一级业务域；无二级模块常驻或遮挡工作区。
- **完成后停止，等待用户确认。**

### Phase 2：交互与动画

- 仅实现第 6 节状态机、hover/focus、点击锁定、点击外部关闭、单面板互斥和动画。
- 不改变模块实际切换、权限、请求、保存、任务或 API。
- 验收：悬停可进入面板；点击锁定；切换域时仅保留一个面板；动画与 reduced-motion 符合规范。
- **完成后停止，等待用户确认。**

### Phase 3：接入已有业务功能

- 复用既有 `data-nav-module`、`showModule()`、权限隐藏、用户菜单和 `Harness` 链接，不变更现有 API、请求字段、权限语义、任务调度或数据库结构。
- 验收：模块选择后显示正确工作区、所属业务域高亮、权限不足模块不显示；现有新增、编辑、保存、删除、运行和调度路径回归通过。
- **完成后停止，等待用户确认。**
