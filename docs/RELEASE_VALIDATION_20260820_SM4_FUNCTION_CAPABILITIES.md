# SM4 函数能力矩阵与 JAR 白名单发布验证报告

验证日期：2026-08-20

验证环境：`192.168.150.128`
发布模式：模式二（发布验证，不执行回滚演练）

## 发布内容

- 密钥来源新增“使用已有密钥版本”，仅复用当前连接下的活动密钥，不登记新密钥版本。
- 每个 Doris 业务库可独立启用或取消加密、解密函数，并支持批量全选、取消及全部能力操作。
- 取消能力会删除该库对应的固定函数和版本函数；不会修改任务、密钥、批次、调度、离线开发快照或业务数据。
- 应用前展示逐库“原能力 → 新能力”差异并要求确认。
- JAR 下载接口增加 `DORIS_SM4_UDF_JAR_ALLOWED_IPS` 来源限制，支持单 IP、CIDR、起止范围和逗号组合。
- 部署记录增加 `encrypt_enabled`、`decrypt_enabled` 两列；旧记录迁移后保持原有双能力启用状态。

## 安全与兼容边界

- 已有密钥必须属于当前 Doris 连接，禁止跨连接复用。
- 新密钥至少需要一个库启用加密函数；已有密钥允许只保留解密能力或清除全部能力。
- 加密批任务只能解析到 `encrypt_enabled=true` 且部署成功的库。
- 128 API 白名单为：`127.0.0.1,::1,192.168.150.128,172.16.0.0/12`。
- 发布前无 active/reserved Celery 任务，SM4 在途批次为 0；三个容器源码均已备份。

- Chrome 自动化连接被本机浏览器插件的可信路径校验阻止，因此本轮未自动完成可见 Chrome 的窗口尺寸与点击保存回读闭环。该限制不影响已完成的接口、静态页面、数据库迁移及运行服务验证；建议用户刷新 128 页面后人工确认能力矩阵布局。
